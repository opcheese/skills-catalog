Get started in one line

Once installed, run kimi inside any project to start a conversation.

macOS / Linux
$ curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
Windows (PowerShell)
PS> irm https://code.kimi.com/kimi-code/install.ps1 | iex
Run anywhere
$ kimi
