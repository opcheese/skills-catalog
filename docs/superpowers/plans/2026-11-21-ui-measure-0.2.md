# ui-measure 0.2 and ui-hill-climb 0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measured building from Figma: authoritative builder pairs, CSS filter shadows, selector resolution and a
default pairs file in ui-measure; a build-time section in its skill; ui-hill-climb picks up those pairs and runs its
judge and proposer on any model.

**Architecture:** Engine changes stay inside ui-measure's existing seams: the proposal type and parser
(`correspondence/`), a new in-page resolver beside the DOM walker (`dom/resolve.ts`), the verifier's rule list, the
effects block of `spec/compare.ts`, and the CLI's proposer selection. ui-hill-climb changes only `hill-measure`'s
proposal order and moves its two model calls behind one runner function in `hilllib.py`.

**Tech Stack:** TypeScript, vitest, Playwright, esbuild (ui-measure); Python 3 stdlib and bash tests (ui-hill-climb).

**Spec:** docs/superpowers/specs/2026-11-21-ui-measure-0.2-design.md

  `HILL_JUDGE_MODEL` unchanged. Exit 75 only from the `kimi` runner.

## Review Focus

- A recorded selector matching an element rendered outside the root (a portal menu appended to `body`): the pair is
  not comparable with note `no element inside root` — never silently dropped, never matched outside. (Task 2)
- An invalid CSS selector in a pairs file (`button[aria-label=Back`): that pair is not comparable `invalid selector`,
  the run completes. (Task 2)
- An authoritative pairs file with zero pairs: verdict `not_comparable`, never `clean`. (Task 3)
- A `filter` holding two drop-shadows plus a blur, against a design with the matching two shadows and a layer blur:
  no effects finding. (Task 4)
- A malformed default pairs file: setup error naming the file, exit 3 — no fallback to "no proposer". (Task 5)
- An unknown `HILL_RUNNER`: exit 2 naming the four valid runners. (Task 9)
